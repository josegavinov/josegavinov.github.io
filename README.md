# Portafolio — Jose Gaviño

Mi portafolio personal: https://josegavinov.github.io

Sitio estático construido con [Astro](https://astro.build) y TypeScript, con cada
proyecto como un archivo markdown validado por esquema. Se despliega solo a
GitHub Pages en cada push a `main`.

```bash
npm install
npm run dev
```

Ver [DESARROLLO.md](DESARROLLO.md) para cómo añadir un proyecto y editar tus datos.
